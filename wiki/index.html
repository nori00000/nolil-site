이름과 정체성

해커팜은 농장의 질문을 기술과 예술로 탐구하는 공유 농장입니다. 주 브랜드는 해커팜, 영문은 HACKER FARM, STUDIO는 작은 보조 표기입니다. 관찰하고, 고쳐 쓰고, 표현하며 다음 사람이 이어갈 기록을 남깁니다.

운영규율과 현재 상태

공유 농장 회원 가입비를 운영 기반으로 설계하며 부동산 임대수익을 기반으로 삼지 않습니다. 회원 유치 실적은 0입니다. 첫 시즌은 정원 12명, 12주 가입비 36만 원, 격주 3시간씩 6회를 기준안으로 정했습니다. 개시일·진행자·세부 지원·환급 조건은 준비 중이며 신청·예약·결제를 받지 않습니다. 개인 작업·사진·기록의 공개와 기여는 자발적입니다. 기술과 예술은 서로 독립된 탐구로 존중합니다.

조사 자료를 최신화하는 방법

자료의 연식만으로 제외하지 않습니다. 원작의 질문·구조·작동 원리를 먼저 기록하고, 현재 구할 수 있는 부품·소프트웨어와 우리 현장에 맞게 바꿉니다. 출처 확인 → 보존할 원리 → 변경 설계 → 작은 시제품 → 현장 시험 → 실패와 재현 방법 기록 순서로 검증합니다. 아래 내용은 적용 계획이며 제작 완료나 성능 검증 결과가 아닙니다.

세 가지 적용 계획

PRJ01 / 설계 · 현장 시험 전

농장의 보이지 않는 하루 ↗

현장의 질문을 먼저 세우고, 관찰과 기술을 연결하는 방식.

  1. 시간·단위·오류를 함께 남기는 관찰 기록
  2. 같은 결과를 다시 만들어 볼 수 있는 한국어 실습
  3. 숫자와 감각을 나란히 읽는 그래프와 표현

다음 확인: 기존 로그의 원본 경로와 형식을 확인하고 재현 예제를 만든다.

PRJ02 / 설계 · 현장 시험 전

다음 사람이 이어 쓰는 도구 ↗

실제 물건의 위치와 상태를 식별번호로 연결하는 단순한 원리.

  1. 휴대전화에서 읽기 쉬운 도구 카드
  2. 고치기 전후와 다음 점검을 남기는 이력
  3. 다음 사람이 찾고 쓰기 쉬운 표찰

다음 확인: 실제 대상 도구와 상태를 확인하고 한 개의 자산 카드를 설계한다.

PRJ03 / 설계 · 현장 시험 전

농장의 빛을 만드는 작업 ↗

빛·종이·에너지를 하나의 표현으로 엮는 발상.

  1. 지금 구할 수 있는 재료와 바꿀 수 있는 구조
  2. 조립과 수리가 가능한 설명
  3. 빛의 의도와 실제 경험을 비교하는 작업 노트

다음 확인: 표현 의도와 사용할 재료를 정리하고 모형 시험 조건을 만든다.

개인 메모와 선택 링크

함께하기 화면의 질문은 화면 메모리에만 남으며 새로고침 시 지워집니다. 브라우저 뒤로가기로 복원될 수 있습니다. 저장 버튼으로 개인 파일을 내려받거나 직접 복사할 수 있습니다. 선택 링크에는 프로젝트와 역할만 포함하고 개인 질문은 포함하지 않습니다. 이 사이트는 회원 신청 폼이나 결제 창이 아닙니다. 별도 분석·광고 추적 스크립트는 사용하지 않습니다. 웹 호스팅 과정의 기술적 요청 처리는 별개입니다.
