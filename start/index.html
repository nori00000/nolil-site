처음이라 궁금한 것들.

기술을 잘 몰라도 괜찮을까요?

관찰·설명·스케치처럼 전문 장비 없이 준비할 행동이 있습니다. 현장 활동에 필요한 경험과 제공할 도움은 활동 조건에 명시합니다.

방문하거나 신청할 수 있나요?

첫 작업일을 준비하고 있습니다. 일정·장소·비용이 안내된 뒤 참여해 주세요. 현재 선택한 내용은 예약이나 신청이 아닙니다.

내 작업을 꼭 공개해야 하나요?

개인 작업·사진·기록의 공개와 기여는 자발적으로 선택합니다. 원자료의 출처와 재사용 조건은 별도로 지킵니다.

작업은 어떻게 이어지나요?

예를 들어, 관찰한 메모에서 질문을 찾고 → 다른 기록과 비교하고 → 질문이나 도구를 바꾸고 → 다음 설명을 남기는 방식입니다. 확정된 서비스 일정이나 실제 회원 성과가 아닌 운영 구상입니다.
