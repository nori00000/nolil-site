02

Small steps
to get started.

For now, these are things you can try at home. We will share on-site dates and support once they are confirmed.

01

Sketch light from memory

Record a memorable scene of light or shade with a sketch or a few words.

Draw or describe it in whichever way suits you; no making experience is needed.
Start here ↗
02

Sketch a path for light

Draw a folded or layered paper shape. Mark where light could pass through.

Start with a sketch; there is no need to buy materials.
Start here ↗
03

Describe the light you need

Write down how bright you want the light to be, where it would be used and how long it would stay on. Component connections will be considered later.

Start by defining requirements; circuit tests require confirmed components and a responsible person.
Start here ↗
