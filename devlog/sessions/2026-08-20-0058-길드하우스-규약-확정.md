# 길드하우스 규약 확정과 사이트 반영

- **날짜**: 2026-08-20 (2026-08-19 주간부터 연속)
- **프로젝트**: nolil-site
- **브랜치**: main

## 작업 요약

길드 사다리(L0~L5)와 농장의 5통화를 홈에 공개하고, 규약 전문 페이지를 신설했다.
이후 환불·해지와 승급 판정 2절을 추가해 규약이 9절이 됐다.
용어 두 개를 바꿨고(구경꾼→첫걸음, 놀일꾼→한솥밥), 결번으로 오판했던 L4를 복원했다.
홍보 스프린트(8/24) 전 진단에서 사이트에 측정기가 0건임을 발견해 자리를 준비했다.

## 변경된 파일

| 파일 | 변경 | 설명 |
|------|------|------|
| `index.html` | 수정 | `#guild` 섹션 신설(사다리 6칸 + 5통화), 용어 교체, L4 복원 |
| `rules.html` | 생성 | 규약 전문 9절 — 요금·등급·운영규칙·5통화·계약·환불·승급 |
| `config.js` | 수정 | 측정기 자리(ga4/naverVerify/naverWcs) — 값이 비면 아무것도 로드 안 함 |

## 핵심 결정

- **신규 CSS는 전부 `.guild-` 접두사로 격리**: 기존 CSS가 88KB라 충돌하면 페이지가 깨진다. 기존 껍데기(wrap/section-head/bar/eyebrow/mint)만 재사용.
- **팔레트에 텍스트 전용 토큰 신설**: `--soft`/`--coral`을 본문에 쓰면 민트 배경 위에서 3.4~3.7:1로 WCAG AA 미달. `--soft-text`/`--coral-text`/`--meta-on-teal`을 신설해 브랜드 토큰은 테두리·배경 전용으로 분리했다.
- **L4는 가격표에 없는 게 아니라 돈이 반대로 흐르는 칸**: 회비 없이 급여를 받으므로 가격 자리에 "회비 없음 · 함께 일함"을 넣고 파선 테두리로 구분했다. 다른 칸과 같은 모양이면 "가격 미정"으로 읽힌다.
- **측정기는 fail-closed**: ID가 비면 스크립트가 하나도 로드되지 않는다. `config.js` 한 곳만 채우면 16개 페이지에서 켜진다.

## 배운 점 (TIL)

- **주석의 사실 주장은 실행되지 않아 어디서도 안 터진다.** codex 검수 6왕복 중 4회가 가드 주석이 사실과 어긋난 문제였다. 조건을 요약하면 틀렸고, 조건 자체를 적자 통과했다.
- **지시서에서 막는 게 검수에서 잡는 것보다 싸다.** rules.html은 AA 미달로 6왕복, index.html은 지시서에 금지 조합을 명시해 0왕복.
- **검수 범위를 델타로 좁히면 토큰이 315k → 7.5k.** 후속 라운드는 "직전 FAIL만"으로 못 박을 것.
- **전역 CSS `h1,h2,h3{margin:0}` 때문에 클래스 없는 `<h3>`는 간격이 사라진다.** 이 페이지의 소제목 관례는 `<h3 class="sub">`.
