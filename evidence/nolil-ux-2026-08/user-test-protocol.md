# 놀일 홈페이지 사용자 검증 프로토콜

## 동의와 기록

“홈페이지가 처음 보는 사람에게 이해되는지 확인하려 합니다. 정답은 없으며 사이트를 평가하는 시간입니다. 이름·전화번호는 기록하지 않고, 녹음·녹화도 하지 않습니다. 언제든 중단할 수 있습니다.”

- 기존 참가자: `E01`부터, 신규·잠재 참가자: `N01`부터 익명 코드 사용
- 이름, 전화, 이메일, 음성, 영상은 저장하지 않음
- 관찰 사실, 발화 요약, 해석, 수정 가설을 분리
- 모집 상태: 실제 주간 방문자 세션 일정 조율 필요. 결과를 임의로 생성하지 않음

## 과업

1. 모바일 hero를 5초 보여준 뒤 “무슨 곳이고, 누구를 위한 곳이며, 무엇을 하면 되나요?”라고 묻는다.
2. “처음 무료로 가볼 모임을 찾아보세요.” 첫 클릭 위치를 기록한다.
3. “가까운 무료 모임을 골라 신청 직전까지 가보세요.” 도움 여부와 완료 여부를 기록한다.
4. “15명 회사 모임을 문의하려면 어디로 가겠습니까?” 클릭 수와 도착 URL을 기록한다.
5. “지금 돈을 내기 망설여지는 이유는 무엇인가요?”라고 묻고 발화를 요약한다.

## 성공 기준

- 5초 회상: 75% 이상이 사람·재능·모임 중 두 요소 이상 언급
- 무료 CTA 첫 클릭: 80% 이상
- 무료 상세 도달: 80% 이상 도움 없이 성공
- 단체 대관: 80% 이상 2회 이내 `group.html` 도달

표본은 5~8명이며 가능하면 기존 참가자 3~4명과 신규·잠재 참가자 3~4명으로 나눈다.

## 세션 기록 템플릿

세션이 끝난 뒤 아래 형식으로 익명 기록만 남긴다. 이름·연락처·원문 녹취·화면 녹화는 저장하지 않는다.

```text
세션 코드: E__ / N__
기기·뷰포트:
동의 확인: 예 / 아니오
5초 회상: 관찰 사실
무료 CTA 첫 클릭: 성공 / 실패 / 도움 필요
무료 상세 도달: 성공 / 실패 / 도움 필요
단체 대관 도달: 성공 / 실패 / 도움 필요
망설임 발화 요약: 개인 식별정보 없이 요약
해석과 관찰 분리:
수정 가설:
검증할 지표:
```

세션 결과는 AI 마케팅 스킬의 입력으로 사용할 때도 익명 요약과 집계값만 사용한다. 결과가 성공 기준에 미달하면 카피를 바로 확정하지 말고, 문제 화면 screenshot·관찰 사실·다음 가설을 함께 검토한다.
