# 놀일 사용자 검증 익명 결과 템플릿

이 파일은 기록 양식입니다. 실제 참여자 결과는 아직 없습니다. 결과를 임의로 채우지 않습니다.

## 기록 원칙

- 참여자 코드는 기존 참가자 `E01`, 신규·잠재 참가자 `N01`부터 사용합니다.
- 이름, 전화번호, 이메일, 음성, 영상, 얼굴 사진, 직장명, 소속 단체명은 기록하지 않습니다.
- 관찰 사실, 발화 요약, 해석, 수정 가설을 분리합니다.
- 직접 인용은 재식별 위험이 없는 짧은 표현만 남기고, 기본값은 요약입니다.
