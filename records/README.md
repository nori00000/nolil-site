# 회원 활동 기록 (records.json)

`{"records": [...]}`, 각 항목: `{date:"YYYY-MM-DD", title, crop, summary(한 문장), image(선택, images/records/…), url(선택)}`
홈 `#records`가 최신순 최대 6장을 렌더합니다. 스키마를 벗어난 항목(날짜 파싱 불가·title 없음)은 그 항목만 빠집니다.
1원천 1카드: 회차 1건 = 기록 1건. 사진은 실제 촬영분만 올립니다.
비어 있으면 홈에는 "첫 회차가 열리면 첫 기록이 여기 올라옵니다" 카드가 그대로 남습니다 — 기록을 지어내지 않습니다.
